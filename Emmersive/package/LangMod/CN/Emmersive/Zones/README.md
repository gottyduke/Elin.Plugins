## 区域背景

文件名：`Zone_<zoneId>@<层>.txt`，例如城镇本身是 `Zone_derphy@0.txt`，其下一层是 `Zone_derphy@-1.txt`。

如果当前层没有对应文件，则使用 `Zone_<zoneId>.txt`，它对该区域的所有层生效。

整个文件就是背景提示词。在世界地图上不会使用。
