## Zone Backgrounds

File name: `Zone_<zoneId>@<level>.txt`, e.g. `Zone_derphy@0.txt` for the town and `Zone_derphy@-1.txt` for the floor
below it.

If there is no file for the current level, `Zone_<zoneId>.txt` is used for all levels of that zone.

The whole file is the background prompt. It is not used on the world map.

Zone ids are listed
in [SourceZone](https://docs.google.com/spreadsheets/d/16-LkHtVqjuN9U0rripjBn-nYwyqqSGg_/edit?gid=1894708317#gid=1894708317).
